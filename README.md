# Tessie for IP-Symcon

Module für IP-Symcon 9.0.

## Enthält
- TessieConfigurator (Typ 4)
- TessieVehicle (Typ 3)

## Hinweise
- Telemetrie WebSocket: Token wird kompatibel über `?access_token=...` in der URL genutzt.
- Optional: Auto-Variablen RAW + zusätzlich metric (psi->bar, mph->km/h, mi->km, °F->°C).
