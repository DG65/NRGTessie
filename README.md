# Tessie for IP-Symcon (Symcon 9.0)

- TessieConfigurator: legt Vehicle + WebSocket Telemetrie an (Create-Chain Reihenfolge für Symcon 9.0)
- TessieVehicle: Auto-Variablen
  - **metrisch** Standard (AutoMetric)
  - RAW optional (AutoAllData)
  - Imperial→Metric Umrechnung (mph→km/h, mi→km, °F→°C, psi→bar)

Hinweis: Telemetrie Auth über `?access_token=...` in WS-URL (kompatibel).
